### What CodeShield does

- **Live scanner:** 23 security rules mapped to CWE and the OWASP Top 10, with data-flow tracking across lines
- **Proof Lab:** every fix is checked twice, failing on the original line and passing on the fix
- **Explained in Arabic:** why each finding is dangerous and how to fix it
- **Academy:** short lessons and a "Vulnerability Hunt" game
- **Private by design:** scanning happens on the user's device; it also works offline
